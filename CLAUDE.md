# Luminet Design Library

Greenfield npm package `@luminet/design-library` — not Inventory or Campaign.

When adding components, follow the Luminet design taxonomy (sizes `xs|sm|md|lg`, semantic colors, CVA + `cn`, tokens in `theme.css`). Phase 1 catalog: Button, TextInput, then remaining form controls.

Build: `npm run build`. Demo: `npm run dev` (playground).
